# 开发环境变量配置

启动本服务前需设置以下环境变量（`application.yaml` 中均为 `${ENV_VAR}` 占位，禁止把明文凭证写入配置/代码/仓库——H4 全局不变量③）：

| 变量 | 含义 | 示例值 |
|---|---|---|
| `DASHSCOPE_API_KEY` | 阿里云百炼（DashScope）API key | `sk-你的key` |
| `DB_PASSWORD` | MySQL 数据库密码（`writing-start` 数据源） | 你的数据库密码 |
| `BGE_MODEL_PATH` | 本地 BGE bge-m3 模型目录（ONNX 推理，`load-on-start: true` 缺则启动报错） | `/Users/Administrator/bge-m3` |

## 方式一：临时设置（当前终端一次有效）

```bash
export DASHSCOPE_API_KEY="sk-你的key"
export DB_PASSWORD="你的数据库密码"
export BGE_MODEL_PATH="/Users/Administrator/bge-m3"
mvn spring-boot:run
```

适合测试；新开终端需重新设置。

## 方式二：持久设置（推荐）

macOS 默认 zsh，写入 `~/.zshrc`，每次打开终端自动生效：

```bash
echo '
export DASHSCOPE_API_KEY="sk-你的key"
export DB_PASSWORD="你的数据库密码"
export BGE_MODEL_PATH="/Users/Administrator/bge-m3"' >> ~/.zshrc
source ~/.zshrc
```

验证：`echo $DASHSCOPE_API_KEY`（能看到值即成功）。

## 方式三：单条命令内联（临时用，不写文件）

```bash
DASHSCOPE_API_KEY="sk-你的key" DB_PASSWORD="你的数据库密码" BGE_MODEL_PATH="/Users/Administrator/bge-m3" mvn spring-boot:run
```

## 方式四：IDEA 运行配置

Run/Debug Configuration → 启动项 → **Environment variables** 填（IDEA 用**分号**分隔）：

```
DASHSCOPE_API_KEY=sk-你的key;DB_PASSWORD=你的数据库密码;BGE_MODEL_PATH=/Users/Administrator/bge-m3
```

## 验证与启动

- 环境变量生效检查：`echo $DASHSCOPE_API_KEY` / `echo $DB_PASSWORD` / `echo $BGE_MODEL_PATH`
- 启动：`mvn spring-boot:run`（模块 `writing-start`，端口 8080）
- 日志观察：`model.llm` / `model.embedding` / `datasource` 初始化成功即配置正确

## 安全提醒

1. **禁止把真实 key/密码写入 `application.yaml`、`*.properties` 或任何会被 git 跟踪的文件**；环境变量在 shell 配置（仓库外）中保存即可。
2. 若 key/密码疑似泄露（如出现在对话、截图、公共仓库中），请立即轮换：阿里云百炼控制台重新生成 API key；MySQL 修改 `root` 密码并同步更新环境变量。
3. CI/生产环境用密钥管理系统（如阿里云 KMS / 密钥管理）注入，不在仓库保存任何凭证。
